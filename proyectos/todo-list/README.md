# ✅ Lista de Tareas

Aplicación web simple desarrollada con **HTML, CSS y JavaScript** que permite crear, completar y eliminar tareas diarias.

Este proyecto fue creado como práctica de **JavaScript básico**, manipulación del DOM y experiencia de usuario (UX).

---

## 🚀 Funcionalidades

- Agregar tareas escribiendo y presionando Enter o el botón
- Marcar tareas como completadas
- Eliminar tareas individuales
- Limpiar tareas completadas
- Limpiar tareas no realizadas
- Contador de tareas completadas
- Iconos automáticos según el texto de la tarea
- Diseño responsive (desktop y mobile)

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome (iconos)

---

## 📱 Responsive Design

La aplicación se adapta correctamente a:
- Escritorio
- Tablets
- Dispositivos móviles
