# Formulario de Contacto

Formulario frontend desarrollado con HTML, CSS y JavaScript.

## Funcionalidades
- Validación de campos obligatorios
- Validación de formato de email
- Mensajes de error claros
- Simulación de envío exitoso
- Diseño responsive

## Tecnologías
- HTML
- CSS
- JavaScript

## Nota
Este proyecto se enfoca en la experiencia de usuario y validaciones frontend.
